## Project Description

This project implements a basic AI Agent using Python and the OpenAI API.

## Objective

The objective is to understand how a Python application can communicate with an AI model through an API.

## Technologies Used

- Python
- OpenAI API
- OpenAI Python SDK
- VS Code
- Git
- GitHub

## Features

- Accepts natural-language user input
- Sends input to an AI model
- Receives an AI-generated response
- Displays the response
- Supports repeated interaction

## How to Run

1. Install Python.
2. Create a virtual environment.
3. Install dependencies.
4. Configure the API key.
5. Run `agent.py`.
